# Signal-Driven Visualization

## 目标

设计一种尽量直接表达声音本身的可视化方式，而不是先把声音解释成节拍、频段、段落、情绪，再去驱动画面。

这里的核心原则是：

- 不做高层语义分析
- 只做最低限度的显示变换
- 让观众自己从画面中感受节奏、密度、冲击、层次

更准确地说，不是“完全不处理”，而是：

- 不显式提取 `beat / onset / bpm / 段落 / bass / mid / high`
- 允许做解码、窗口切片、重采样、轻微平滑、残影

## 约束

任何声音到画面的方案，至少都要经过三步：

1. 从音频文件解码出连续样本值
2. 把样本值映射到画布空间
3. 把连续画面按帧输出成视频

所以“完全零处理”并不存在。真正能控制的是：

- 是否先做“音乐理解”
- 是否让中间结果变成一组高层特征

本方向选择的是：

- 保留信号
- 不先做解释

## 方案 A：波前式

这是当前优先推荐的方案。

### 核心思路

- 左右声道的原始时域波形，从画面左右两侧持续送入
- 它们像波前一样向中间传播
- 横向位置表示传播距离或时间延迟
- 纵向位移直接对应样本振幅
- 多层线条来自历史残影，而不是独立生成的多条“语义轮廓”

### 特点

- 最接近“声音在空间里传播”的直觉
- 不需要节拍检测、频带分析或段落识别
- 低频会自然显得宽、慢、厚
- 高频会自然显得密、碎、急
- 比普通示波器图更有空间感

### 风险

- 如果直接画普通波形，很容易退化成示波器截图
- 需要对“传播速度、残影、亮度衰减、线条组织”做设计

### 适用性

- 最适合当前这套黑底白线、居中对称、工业感较强的审美方向

## 方案 B：声谱书写式

### 核心思路

- 不把每一刻的声音画成当前帧里的完整结构
- 而是让声音像在画布上持续“写字”
- 新的波形痕迹叠加在旧痕迹上
- 旧痕迹逐渐衰减

### 特点

- 更强调连续性和纹理
- 更像“声音留下的痕迹”
- 更氛围化

### 风险

- 节奏感和方向感未必有波前式强
- 如果衰减控制不好，容易发灰、发糊

### 适用性

- 适合做更偏长曝光、胶片感、余辉感的版本

## 方案 C：相位图 / 李萨如式

### 核心思路

- 直接把左右声道映射成二维轨迹
- 例如 `x = left(t)`，`y = right(t)`
- 轨迹随时间演化，形成动态图形

### 特点

- 非常原始、直接
- stereo 结构会被清楚地显现
- 不需要节拍和频率层面的语义分析

### 风险

- 更抽象
- 不一定符合当前“横向展开”的视觉目标
- 可读性取决于声音本身的 stereo 结构

### 适用性

- 适合做更实验、更图形化的版本

## 当前推荐

当前推荐优先实现 **方案 A：波前式**。

原因：

- 仍然足够直接，不依赖高层分析
- 同时比普通时域波形更有空间组织
- 更容易与当前偏极简、对称、黑白线框的视觉语言兼容

## 与现有主题的区别

现有主题大多是：

- `feature-driven`
- 先提取特征，再驱动画面

本方向是：

- `signal-driven`
- 尽量直接把时域信号显影为画面

两者不是参数差异，而是建模思路不同。

## 后续实现建议

实现顺序建议如下：

1. 先做波前式的静态规格与时序规则
2. 再做一个最小实现，只验证“原始波形向中间传播”的感觉
3. 然后单独调：
   - 传播速度
   - 残影层数
   - 亮度压缩
   - 线条组织
4. 最后再考虑是否尝试：
   - 声谱书写式
   - 相位图 / 李萨如式
