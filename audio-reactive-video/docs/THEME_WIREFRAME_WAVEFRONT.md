# Theme Spec: wireframe_wavefront

## 目标

实现一个不依赖高层音乐分析的黑白线框主题：

- 输入直接来自原始时域波形
- 左右声道像波前一样从画面两端推进到中间
- 画面更像“声音被显影”，而不是“音乐被解释后画出来”

## 设计原则

- 不显式使用 `beat / onset / bpm / bands`
- 不基于节拍事件触发视觉效果
- 不做传统频谱柱
- 不做填充，主体以细线和残影构成
- 只允许最低限度的显示处理：
  - 窗口切片
  - 重采样
  - 轻微平滑
  - 余辉 / 残影
  - 动态范围压缩

## 画面规格

- 背景：纯黑
- 主体：白色细线
- 构图：水平中轴，左右对称
- 画面中心：两股波前相遇的位置，不额外做语义特效
- 视觉风格：克制、干净、工业感

## 输入

输入不是高层分析特征，而是解码后的原始 PCM：

- `left[t]`
- `right[t]`

如果原文件是单声道：

- 左右使用同一份数据

## 基本模型

### 1. 波形块

每一帧取左右声道最近一小段时域样本，称为“波形块”。

推荐窗口范围：

- `20ms ~ 80ms`

窗口太短：

- 画面会过于抖动

窗口太长：

- 画面会变钝

### 2. 注入

- 左声道波形块从左边缘注入
- 右声道波形块从右边缘注入

注入的不是单个点，而是一小段连续波形。

### 3. 传播

- 已注入的波形块按固定速度向中间移动
- 越靠近中心，越“旧”
- 越靠近边缘，越“新”

这意味着横向位置本质上表示：

- 传播距离
- 或者声音样本的“年龄”

### 4. 相遇

- 左右波前在中心自然重叠
- 中心不是节拍触发器，只是空间上的相遇区
- 重叠后的亮度或厚度可以略微增加，但不做强特效

## 声音到画面的映射

### 横向

- 表示样本从边缘注入后经过的时间
- 新样本在外侧
- 旧样本向中间推进

### 纵向

- 直接表示振幅
- `y = f(sample)`

建议使用轻度压缩函数，而不是线性映射：

- 避免大振幅直接打穿画面
- 保留小振幅的可见性

例如：

- `y = sign(x) * |x|^gamma`
- 其中 `gamma` 在 `0.65 ~ 0.9`

### 亮度

- 由局部重叠密度和时间衰减决定
- 不由节拍事件单独决定

### 线条层

- 多层线条来自时间残影
- 不来自多个独立结构

## 关键视觉效果

### 1. 波前感

观众应该看到：

- 声音从左右边缘“射入”
- 沿着中轴上下起伏
- 一路向中心推进

不应该看到：

- 原地抖动的示波线
- 固定在中心的单个大峰

### 2. 局部尺度差异

在不做频谱分析的前提下，频率差异应通过时域形态自然显现：

- 低频：峰宽更大、起伏更慢
- 高频：峰更密、更细、更急
- 混合音色：不同尺度的纹理叠加

### 3. 残影层次

历史残影应满足：

- 越旧越淡
- 越旧越贴近主轴，或略微收束
- 不应变成独立的另一组结构

## 技术实现建议

### 阶段 1：缓冲

维护左右声道的波前缓冲区：

- `left_wavefront_buffer`
- `right_wavefront_buffer`

每帧：

- 注入新的波形块
- 将已有波形整体向中间平移

### 阶段 2：重采样显示

显示时：

- 将缓冲区重采样到画布横向采样点数
- 使用 `min/max` 包络优先于简单平均

原因：

- `min/max` 更能保留瞬态和尖峰

### 阶段 3：残影

保留最近若干帧的波前显示结果：

- `history[0]` 当前帧
- `history[1..N]` 旧帧

绘制时：

- 当前帧最亮
- 越旧越淡
- 可带极弱的轴向收束

### 阶段 4：后期

后期只允许：

- 极弱 glow
- 极弱亮度压缩

不建议：

- bloom
- 粒子
- 噪声纹理
- 大面积模糊

## 建议参数

- `sample_window_ms`
- `injection_span_px`
- `propagation_speed_px_per_frame`
- `history_size`
- `history_decay`
- `amplitude_gamma`
- `amplitude_scale`
- `axis_pull`
- `glow_radius`
- `glow_opacity`

## MVP 实现边界

第一版只验证以下几点：

1. 左右波形块确实从边缘向中间推进
2. 纵向位移直接来自原始时域振幅
3. 画面有残影层次
4. 中心相遇自然可见
5. 不依赖 `beat / onset / bands`

第一版不追求：

- 音乐结构可读性最大化
- 节拍强调
- 强烈戏剧化视觉事件

## 与参考风格的关系

这个主题与之前的 `wireframe_pulses` 不同：

- `wireframe_pulses` 是离散脉冲模型
- `wireframe_wavefront` 是连续时域波前模型

前者更像“由声音触发的图形事件”，
后者更像“声音本身在空间中的显影”。
